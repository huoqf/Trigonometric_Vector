# 工作流：真题录入与训练 (Add Real Question)

## 目的
规范化录入一道高考真题并将其接入动态交互组件的流程。

## 步骤
1. **数据准备**：将题目、选项、解析整理为标准 JSON 格式并存入题库系统。
2. **场景映射**：分析题目考查的知识点，并与现有的 `features` 或 `components` 建立映射（如：解三角形面积最值）。
3. **状态初始化**：编写特定题目的初始化钩子函数，用于在进入真题时锁定 `store` 中的初始边界条件。
4. **提示引导生成**：按反向引导律（Socratic Guidance Rule）补充渐进式的交互提示与解题辅助线组件。
5. **测试验证**：确保答题逻辑、错题记录及错题回放功能工作正常。
