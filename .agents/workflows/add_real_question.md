# Workflow: 接入真题 (Add Real Question)

## Title
接入高考真题训练工作流 (Add Real Question Workflow)

## Description
此工作流定义了在 MathVision 系统中，将一道高考数学真题转化为交互式动态训练题的标准流程。该流程确保真题不仅仅被当作“静态文字”展示，而是能够被拆解为可操作的几何/代数模型。

## Steps

1. **题干分析与题库录入**
   - **目标**：将题目结构化存入 JSON 题库。
   - **操作**：
     - 分析真题的核心考点，打上知识点标签（如：解三角形最值、奔驰定理、点积）。
     - 将题干、配图数据、选项、标准答案及解析，录入到 `src/data/questions/` 对应的 JSON 文件中。
     - 构建题目的“解题思路树”节点数据，用于提供渐进式提示。

2. **识别动态参数与场景**
   - **目标**：找出题目中可以被“动态化”的条件。
   - **操作**：
     - 如果题目有固定已知条件（如周长固定），则将其设定为 Store 中的约束条件。
     - 找出题目中的变量（如动点位置、夹角大小），将其映射为用户可拖拽的 UI 控件或基底变量。

3. **关联互动实验组件**
   - **目标**：重用现有的几何动画能力来辅助解题。
   - **操作**：
     - 在真题组件中引入相应的实验组件（如引入 `DynamicTriangle` 或是 `VectorDecomposition`）。
     - 将真题的题库参数传入组件，进行初始化渲染。

4. **渐进式提示与反向引导开发**
   - **目标**：实现在不直接给出答案的情况下辅导学生。
   - **操作**：
     - 开发“提示按钮”组件。用户点击提示时，依据“解题思路树”层层展示线索。
     - 第一层提示通常是图形上的变化（如高亮某条辅助线或提示拖动某个点观察极值）。
     - 最后一层提示才是具体的代数演算步骤。

5. **错题与数据回收点埋点**
   - **目标**：记录用户的学习路径。
   - **操作**：
     - 在用户提交答案时，调用 `useRecordStore` 记录正误状态和所用时间。
     - 记录用户在此题中使用了哪些提示，以便后续生成知识盲区图谱。

6. **测试与审查**
   - **操作**：
     - 验证极值情况下的图形是否正确。
     - 验证 JSON 数据结构解析无误，排版渲染正常（KaTeX/LaTeX）。
