# Workflow: 新增知识点实验 (New Knowledge Experiment)

## Title
新增知识点实验开发工作流 (New Knowledge Experiment Development Workflow)

## Description
此工作流定义了在 MathVision 系统中，从零开始设计并实现一个全新的交互式数学知识点实验模块的标准流程。它确保新模块符合“视觉感知优先”、“向量优先”以及“三屏联动”的核心设计要求。

## Steps

1. **需求分析与数学建模**
   - **目标**：理解知识点本质，寻找最直观的几何/物理映射。
   - **操作**：
     - 如果知识点涉及方向、力学、距离、投影等，强制使用**向量模型**。
     - 确定知识点的基底自变量（如角度、拖拽点坐标、向量长度等）。
     - 确定因变量与派生状态（如生成的三角形面积、点积数值、函数曲线值）。

2. **状态架构设计**
   - **目标**：在 Zustand store 中建立可靠的数据流闭环。
   - **操作**：
     - 在 `src/store/useMathState.js` 或对应子 store 中新增必需的基底状态。
     - 编写 Getter/Selector 处理数学对象的衍生计算。
     - 添加 Actions 用于响应拖拽等用户输入。

3. **视觉布局与组件搭建 (三屏联动)**
   - **目标**：构建“操作区 - 联动区 - 数值区”的标准布局。
   - **操作**：
     - 根据 `ui_rules.md` 搭建页面框架。
     - 引入通用 SVG/Canvas 组件搭建左侧核心几何操作区。
     - 右侧/下方搭建动态数值面板与函数曲线区域。

4. **交互联动与防抖测试**
   - **目标**：保证拖拽交互在 60FPS 下平滑运行且无计算溢出。
   - **操作**：
     - 绑定鼠标/触摸拖拽事件到状态 Actions。
     - 添加计算边界防护（如除以 0、tan(π/2) 的截断处理）。
     - 测试联动区域（如拖动向量时，点积数值和曲线是否即时响应）。

5. **反向引导 (苏格拉底提问) 植入**
   - **目标**：提升教学启发性。
   - **操作**：
     - 依据 `math_rules.md`，在实验入口处添加轻量化提问组件（如：“试着拖动点 A，看看面积是如何变化的？”）。
     - 设置用户首次交互后关闭提问、展示解析结果的逻辑。

6. **联调与 Code Review**
   - **目标**：确保符合各项硬性规则。
   - **检查清单**：
     - [ ] 是否存在干瘪无交互的公式页？（有则重构）
     - [ ] 向量定义是否优先于解析推导？
     - [ ] 页面在多端下响应式表现是否正常？
